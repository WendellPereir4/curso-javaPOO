# Projeto POO Java

Projeto desenvolvido durante meus estudos de Programação Orientada a Objetos (POO) em Java.

## Conceitos praticados

- Classes e objetos
- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Classes abstratas
- Métodos e construtores
- Sobrescrita de métodos (`@Override`)
- `extends`
- `static`

## Tecnologias

- Java
- IntelliJ IDEA

## Objetivo

Praticar os principais conceitos de Programação Orientada a Objetos
e consolidar minha base para desenvolvimento Backend Java.
